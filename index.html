Crop JPG, PNG and WEBP Images

Image cropping is useful when you need to remove unwanted edges, focus on a subject, prepare a profile picture, create a square image, or fit a photo into a social media layout. CathyHub supports common JPG, PNG and WEBP input images and provides simple controls for choosing the crop ratio and dimensions.

Popular Image Crop Sizes

The built-in aspect ratios make common cropping tasks easier. Use 1:1 for square images, 4:5 for portrait layouts, 16:9 for landscape images, or 9:16 for vertical story-style images. You can also use the free ratio option when you do not want to follow a fixed proportion.

How to Crop an Image Online

  1. Click Choose Image and select a JPG, PNG or WEBP file.
  2. Choose an aspect ratio or use the free option.
  3. Set the desired width and height in pixels.
  4. Click Crop to create the cropped image.
  5. Download the cropped image.

Privacy-Friendly Image Cropping

CathyHub is designed for browser-based processing. Your selected image does not need to be uploaded to a server for the cropping operation, making the tool convenient for quick everyday image editing.
